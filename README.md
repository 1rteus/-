# Финансовый трекер

PWA-приложение для учёта расходов с автокалькуляцией недельной квоты.

## Функции

- 📊 **Два режима**: неделя / месяц
- 🎯 **Автокалькуляция квоты**: указываете месячный доход + фиксированные расходы (накопления 200₽, проезд 54₽, телефон 57₽) — приложение само считает квоту на неделю и доступную сумму в месяц
- 🔴 **Умное кольцо**: 2 кольца — квота (жёлтое) и расходы (красное)
- ⚠️ **Предупреждение**: при остатке ≤ 5 ₽ кольцо горит красным, показывает остаток
- ➕ **Только расходы**: 3 категории — еда 🍔, развлечения 🎮, подарки 🎁
- 🗑️ **Очистка данных**: кнопка в настройках удаляет всё
- 📱 **PWA**: устанавливается на главный экран
- 💾 **Локальное хранение**: localStorage
- 🌙 **Тёмная тема** с градиентами и анимациями

## Настройка квоты

В настройках укажите:
1. **Доход в месяц** — ваш месячный доход
2. **Накопления** — сколько откладываете (по умолчанию 200₽)
3. **Проезд** — транспорт (по умолчанию 54₽)
4. **Телефон** — связь (по умолчанию 57₽)

Формула:  
`Доступно в месяц = Доход − Накопления − Проезд − Телефон`  
`Недельная квота = Доступно в месяц ÷ 4.33`

На главном экране видно:
- **Круг**: недельная квота + потрачено
- **Карточки**: потрачено / остаток недели / доступно в месяц
- **Разбор квоты**: пошаговый расчёт

## Развёртывание на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы в корень
3. Settings → Pages → Source: "Deploy from a branch", Branch: "main", Folder: "/ (root)"
4. Сайт: `https://username.github.io/repo-name/`

## Локальный запуск

```bash
cd finance-tracker
python3 -m http.server 8000
# откройте http://localhost:8000
```
